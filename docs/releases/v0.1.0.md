# AI Knowledge Hub v0.1.0 — Grounded RAG Foundation

Java knowledge backend with an explicit, evaluated Retrieval-Augmented Generation pipeline. Local-first Ollama operation requires no paid API. This foundation makes retrieval, evidence decisions, source provenance and failure handling inspectable.

## Highlights

- Java 21 target, Spring Boot 4.2.0 and Spring AI 2.1.0.
- PostgreSQL 17 + pgvector 0.8.7; Flyway-managed schema.
- TXT/MD/PDF ingestion with SHA-256 idempotency, bounded parsing/chunking, versioned atomic indexing and explicit retry/reindex.
- Mandatory knowledge-base scoping in retrieval queries; exact semantic retrieval, PostgreSQL lexical FTS and hybrid RRF available for comparison.
- Evidence filtering and bounded context assembly; grounded structured generation, backend-controlled source IDs/quotes, abstention and explicit source-conflict responses.
- Prompt-injection mitigation, predictable provider failures, Micrometer/ECS observability, OpenAPI, Docker Compose and Java 21 CI.

## Validation

**17 unit + 10 integration = 27 tests**, zero failures, errors or skips. Integration gates use real PostgreSQL/pgvector with deliberate deterministic embedding/chat doubles. Ollama is not a mandatory CI dependency.

Manual real-model evaluation used **nomic-embed-text:v1.5** (768 dimensions) and **qwen3:1.7b** through local Ollama: **10/10 golden cases passed**. Cases cover explicit answers, paraphrase, distributed evidence, distractors, absent answers, KB isolation with a positive control, injection filtering, citation validity and conflicting sources. Intermediate failed runs and limitations are preserved in the report.

## Retrieval

Measured on a small controlled corpus, K=3, document-level macro averages over eight answerable cases. Two negative cases are assessed separately through abstention/isolation gates.

| Strategy | Recall@3 | Precision@3 | MRR | Hit Rate |
|---|---:|---:|---:|---:|
| VECTOR real | 1.0000 | 0.4167 | 1.0000 | 1.0000 |
| LEXICAL | 1.0000 | 0.4167 | 1.0000 | 1.0000 |
| HYBRID real | 1.0000 | 0.4167 | 1.0000 | 1.0000 |

No strategy superiority is established by this small corpus. The deterministic integration baseline is a separate measurement, not real-model semantic-quality evidence. Generation retains the vector baseline; threshold and RRF were not tuned during release preparation.

## AI evaluation

**Spring AI RelevancyEvaluator: 7/8**; the negative case was conflicting evidence. The same Qwen model acts as generator and judge, introducing self-evaluation bias. This is complementary probabilistic evidence, not a deterministic proof or a reason to hide the disagreement. The conflict response explicitly warns against a single definitive conclusion and cites both sources.

## Limitations

- Small controlled corpus; results do not establish general accuracy or eliminate hallucinations.
- Unauthenticated API binds to loopback by default. KB isolation is a query/integrity boundary, not authorization.
- Prompt injection is **mitigated, not solved**. Citation provenance does not prove universal semantic entailment; conflict detection remains model-dependent.
- Model variability and cold-start latency remain relevant; the initial cold chat exceeded its deadline.
- Parsing limits reduce resource abuse but are not a hardened PDF sandbox.
- No frontend, autonomous agents or tools/actions. No learned reranker is enabled.
